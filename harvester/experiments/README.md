# Experimentos

Scripts y notas desechables para decidir estrategias antes de convertirlas en
adaptadores. Cada experimento deja una conclusión escrita aquí; el código que
sobreviva se mueve a `src/`. No guardes datos personales ni capturas con
información de clientes en Git.

| # | Pregunta | Resultado esperado | Estado |
| --- | --- | --- | --- |
| E1 | ¿Cuántas ferreterías reales exponen JSON-LD, sitemap o una plataforma conocida (Shopify, WooCommerce, Tiendanube)? | Tabla de cobertura por estrategia | Pendiente |
| E2 | ¿Qué expone una página de Facebook sin sesión con Playwright y cuánto tarda en pedir login? | Viabilidad del respaldo para terceros | Pendiente |
| E3 | ¿`wa.me/c/<número>` muestra el catálogo en un navegador? | Sí/no y campos visibles | Pendiente |
| E4 | Precisión y costo de modelos de visión sobre ~30 imágenes reales | Precisión por campo y costo por imagen | Pendiente |
| E5 | ¿Las ferreterías aceptarían conectar su Facebook o reenviar archivos a un número de Obrifive? | Validación con clientes | Pendiente |
